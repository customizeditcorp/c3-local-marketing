# Despublicar el sitio C3 Marketing Hub

No puedo despublicar el sitio desde el chat. Tienes que hacerlo tú, en la configuración del proyecto.

## Pasos
1. En el editor de Lovable, abre **Project settings** (Configuración del proyecto).
2. Busca la sección de publicación o dominios.
3. Haz clic en **Unpublish**.

## Qué pasará
- `https://c3-local-marketing.lovable.app` dejará de funcionar para los visitantes.
- La página de la base de conocimiento (`/kb.html`) que usa tu chatbot también se apagará, así que el chatbot ya no podrá leerla.
- El dominio `c3marketinghub.com` tampoco mostrará nada.
- No se borra nada: el sitio, su contenido y tu repositorio de GitHub se quedan igual. Puedes volver a publicarlo cuando quieras.

## Cambios en la página
Ninguno.
